Why This Matters:

- `homepage`: Tells React where the app lives (not root `/`)
- `predeploy`: Runs build automatically before deploy
- `gh-pages`: Handles pushing to the gh-pages branch


File 2: vite.config.js (Path Resolution)

```
JavaScript// vite.config.js
// ═══════════════════════════════════════════════════════════════
// CRITICAL: base path must match your GitHub repo name
// Community fix: 90% of blank pages are wrong base path
// ═══════════════════════════════════════════════════════════════

import { defineConfig } from 'vite';
import react from '@vitejs/plugin-react';
import path from 'path';

export default defineConfig({
  plugins: [react()],
  
  // ⚠️ CRITICAL: Change 'YOUR_REPO_NAME' to your actual repo name
  base: '/YOUR_REPO_NAME/',
  
  resolve: {
    alias: {
      '@': path.resolve(__dirname, './src'),
    },
  },
  
  build: {
    outDir: 'dist',
    sourcemap: false, // Disable for production (smaller bundle)
    
    // Fix for large chunks warning
    rollupOptions: {
      output: {
        manualChunks: {
          vendor: ['react', 'react-dom', 'react-router-dom'],
        },
      },
    },
  },
});
```


File 3: Router Configuration (The #1 Fix)

```
React// src/App.jsx
// ═══════════════════════════════════════════════════════════════
// CRITICAL: Use HashRouter for GitHub Pages
// Community consensus: BrowserRouter WILL break on static hosts
// ═══════════════════════════════════════════════════════════════

import React from 'react';
// ❌ DON'T: import { BrowserRouter } from 'react-router-dom';
// ✅ DO: Use HashRouter for GitHub Pages
import { HashRouter, Routes, Route } from 'react-router-dom';

import Index from './pages/Index';
import ReceiptPage from './pages/ReceiptPage';
import TemplatePage from './pages/TemplatePage';

function App() {
  return (
    // HashRouter adds /#/ to URLs but works perfectly on static hosts
    // Example: https://user.github.io/repo/#/receipt
    <HashRouter>
      <Routes>
        <Route path="/" element={<Index />} />
        <Route path="/receipt" element={<ReceiptPage />} />
        <Route path="/template" element={<TemplatePage />} />
        {/* Catch-all for 404 */}
        <Route path="*" element={<Index />} />
      </Routes>
    </HashRouter>
  );
}

export default App;
```

Why HashRouter?:

```

├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  BrowserRouter (❌ Breaks)                                         │
│  ─────────────────────────                                         │
│  URL: https://user.github.io/repo/receipt                          │
│  Problem: GitHub serves index.html only for /repo/                 │
│  Result: 404 error on direct navigation or refresh                 │
│                                                                     │
│  HashRouter (✅ Works)                                             │
│  ────────────────────                                              │
│  URL: https://user.github.io/repo/#/receipt                        │
│  Why: Everything after # is client-side only                       │
│  Result: Works on refresh, direct links, everything                │
│                                                                     │

```

Stage 3: GitHub Actions Deployment (Automated)

Purpose: Never manually deploy again. Push to main = auto-deploy.

```
YAML# .github/workflows/deploy.yml
# ═══════════════════════════════════════════════════════════════
# AUTO-DEPLOY TO GITHUB PAGES
# Triggers on every push to main branch
# ═══════════════════════════════════════════════════════════════

name: Deploy to GitHub Pages

on:
  push:
    branches: [main]
  # Allow manual trigger from Actions tab
  workflow_dispatch:

# Required permissions for GitHub Pages
permissions:
  contents: read
  pages: write
  id-token: write

# Prevent concurrent deploys
concurrency:
  group: 'pages'
  cancel-in-progress: true

jobs:
  # ─────────────────────────────────────────────────────────────
  # BUILD JOB
  # ─────────────────────────────────────────────────────────────
  build:
    runs-on: ubuntu-latest
    
    steps:
      # Step 1: Checkout code
      - name: Checkout
        uses: actions/checkout@v4
      
      # Step 2: Setup Node.js (use LTS version)
      - name: Setup Node
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'
      
      # Step 3: Install dependencies
      # Using 'ci' instead of 'install' for clean, reproducible builds
      - name: Install dependencies
        run: npm ci
      
      # Step 4: Build the project
      - name: Build
        run: npm run build
      
      # Step 5: Add .nojekyll (in case it's not in public/)
      - name: Add .nojekyll
        run: touch dist/.nojekyll
      
      # Step 6: Setup Pages
      - name: Setup Pages
        uses: actions/configure-pages@v4
      
      # Step 7: Upload artifact
      - name: Upload artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: './dist'

  # ─────────────────────────────────────────────────────────────
  # DEPLOY JOB
  # ─────────────────────────────────────────────────────────────
  deploy:
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    needs: build
    
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

Fix #2: Asset Path Issues

```
React// ═══════════════════════════════════════════════════════════════
// CORRECT WAY TO REFERENCE ASSETS
// ═══════════════════════════════════════════════════════════════

// ❌ WRONG - Absolute paths break on GitHub Pages
<img src="/logo.png" />
<img src="/images/hero.jpg" />

// ✅ CORRECT - Relative paths work everywhere
<img src="./logo.png" />
<img src="./images/hero.jpg" />

// ✅ ALSO CORRECT - Import in JavaScript
import logo from './assets/logo.png';
<img src={logo} />

// ✅ FOR PUBLIC FOLDER - Use import.meta.env.BASE_URL
<img src={`${import.meta.env.BASE_URL}logo.png`} />
```
